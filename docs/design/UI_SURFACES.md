## Систем түвшний ажил (дэлгэц биш, гэхдээ бүх дэлгэцэд нөлөөлнө)

1. **Типографи** — одоо `NotoSans` (кирилл бүрэн, гэхдээ зөвхөн ажиллагааны сонголт).
   `BRAND.md`-д «wordmark-ийн жинхэнэ фонт» дутуу гэж тэмдэглэсэн хэвээр.
   Гарчиг/их бие/тоо гэсэн 3 үүргийн хослол сонгох.
2. **Дизайн систем** — `theme/takhi_theme.dart` одоо зөвхөн өнгө.
   Зай, радиус, сүүдэр, гадаргуугийн шатлал, motion токен алга.
3. **Компонентын сан** — `PrimaryButton` ганцаараа. Хоёрдогч/аюултай товч,
   карт, оролтын талбар, badge, жагсаалтын мөр стандартчлагдаагүй.
4. **Хоосон / ачаалж буй / алдааны төлөв** — тогтсон хэв маяг байхгүй,
   дэлгэц болгон өөрөөрөө шийдсэн.
5. **Motion** — шилжилт, ачаалалт, төлөв солигдох хөдөлгөөн огт байхгүй.
6. **Splash** — Андройдын өгөгдмөл. Брэндийн эхлэлийн дэлгэц хийгээгүй.

## Товч дүгнэлт

- Заавал дизайн хийх: **31 дэлгэц** (P0 5, P1 8, P2 12, P3 4, төлөв 2).
- Гэхдээ **эхлэх ёстой газар нь дэлгэц биш** — типографи + дизайн систем (систем түвшний 1, 2).
  Тэдгээрийг эхлээд тогтоохгүй бол 31 дэлгэцийг хоёр удаа зурах болно.
- Хэрэв цөөн тооны дэлгэцээр эхлэх бол: **P0-гийн 5** нь аппын шинж чанарыг
  90% тодорхойлно (нүүр, ажиллаж буй таксиметр, саналын жагсаалт, идэвхтэй аялал, SOS).
