# Зурган хяналт

> Дэлгэц бүрийн **жинхэнэ зураг** байх ёстой. Шинэ маршрут нэмээд зураг нэмээгүй бол
> тест унана: [`app/test/design_system_audit_test.dart`](../../app/test/design_system_audit_test.dart)
> → «every route in router.dart has at least one design screenshot».

## Яагаад

Энэ сессид хоёр алдаа **зөвхөн зургаас** олдсон, тест бүгд ногоон байхад:

| Алдаа | Тестийн байдал |
|---|---|
| `12443₮` — ₮ тэмдэг цифр дээрээ давхарласан | 552 тест ногоон |
| «Түр зогсоох» → `▯▯▯ ▯▯▯▯▯▯▯` хоосон хайрцаг | 565 тест ногоон |

Шалтгаан нь энгийн: тест **«виджет байна»** гэдгийг л батална. **«Уншигдаж байна»**
гэдгийг батлахгүй. `find.text('Түр зогсоох')` нь глиф хоосон хайрцаг болсон ч
олдсоор байна.

Тиймээс зураг бол нэмэлт биш — цорын ганц арга. Харин «зураг авахаа санах» нь
хүний санамж дээр тогтдог тул тестээр механик болгосон.

## Хоосон хайрцгийг машин барина

Дээрх хоёр алдааны *хоёул* нь фонтод байхгүй тэмдэг байсан. Гурав дахь удаа
(«≈ 9 322 ₮» → «▯ 9 322 ₮») давтагдсаны дараа энэ ангийг нүдэн хяналтаас
салгаж механик болгосон:

**[`app/test/font_coverage_test.dart`](../../app/test/font_coverage_test.dart)**
нь багцалсан `NotoSans-Regular.ttf`-ийн `cmap` хүснэгтийг уншиж, `app_mn.arb` ба
`app_en.arb` доторх **тэмдэг бүрийг** тулгана. Глиф байхгүй бол тест унана —
зураг харах хүн байгаа эсэхээс үл хамааран.

Тест өөрөө өөрийгөө шалгадаг: `Ө` ба `₮` заавал **олдох** ёстой, `≈` заавал
**олдохгүй** байх ёстой. Ингэснээр «бүгд байна» гэж худал хариулдаг уншигч
чимээгүй нэвтэрч чадахгүй.

Энэ нь зурган хяналтыг **орлохгүй**: таслагдсан текст, давхарласан элемент,
хоосон дэлгэц зэргийг зөвхөн зураг л барина. Гагцхүү ▯ гэдэг нэг анги нь
хүний санамжаас гарлаа.

## Дүрэм — юу заавал хамрагдах вэ

**`app/lib/router.dart`-ын `GoRoute` бүрд `app/test/golden/images/` дор
ядаж нэг `.png` байх ёстой.**

Харгалзуулах арга: маршрут бүр **файлын нэрийн угтвар** зарлана. Файлын нэр тэр
угтвараар эхэлбэл тэр маршрутын зураг гэж тооцно.

| Маршрут | Угтвар |
|---|---|
| `/` | `onboarding_` |
| `/seed` | `seed_` |
| `/restore` | `restore_` |
| `/home` | `home_`, `sos_` |
| `/ride/passenger` | `passenger_`, `trip_`, `call_` |
| `/ride/driver` | `driver_offer_`, `driver_awarded_`, `qr_capture_`, `trip_`, `call_` |
| `/meter` | `meter_` |
| `/settings` | `settings_menu_` |
| `/settings/phone-share` | `phone_share_` |
| `/settings/driver-profile` | `driver_profile_` |
| `/settings/legal` | `legal_notice_` |

Маршрутын нэрээс зургийн нэрийг автоматаар гаргадаггүй: маршрут нь **хэн жолоодож
байгааг** нэрлэдэг (`/ride/passenger`), зураг нь **дэлгэц дээр юу байгааг**
(`trip_fare_confirm_light`). Хоёр толь бичиг өөр, цаашид ч өөр байна.

Тест **хоёр тийш** шалгана, ингэснээр хүснэгт чимээгүй хоцрохгүй:

1. Маршрут бүр хүснэгтэд эсвэл үл хамаарах жагсаалтад байх ёстой.
2. Зарласан угтвар бүр ядаж нэг файлтай таарах ёстой (үхсэн мөр байхгүй).
3. Хавтас доторх файл бүр ямар нэг маршрутад харьяалагдах ёстой (өнчин зураг байхгүй).

## Юу нь үл хамаарах ба яагаад

Бүрэн жагсаалт нь тест дотор `_routesWithoutScreenshots` ба `_unphotographedStates`
хэсэгт **шалтгаан бүртэй нь** бичээстэй байгаа. Гурван төрлийн шалтгаан л
зөвшөөрөгдөнө:

- **Давхардал** — зураг нь одоо байгаагийн дэд олонлог эсвэл пикселээр бараг ялгагдахгүй.
  Ж: `/settings/emergency-contact` (S29) нь `phone_share_settings_light`-тэй нэг
  талбар + нэг товч, зөвхөн `SwitchListTile`-аар л ялгаатай.
- **Хоосон** — зураг нь нэг өнгийн тэгш өнцөгт болно. Ж: splash (S33).
- **Хүрэх боломжгүй / апп зурдаггүй** — кодын хамгаалалтын салаа, ОС-ийн хуваалцах
  цонх (S25), вэб хуудас (S26).

«Тайзлахад хэцүү байсан» гэдэг шалтгаан **биш**.

Үл хамаарах мөр бүр өөрийн байх ёстой байсан файлын нэрээ агуулна. Хэн нэгэн тэр
зургийг авбал тест «энэ мөр хоцрогдсон, устга» гэж хэлнэ.

## Зургийг яаж дахин гаргах вэ

```sh
cd app
flutter test --update-goldens --run-skipped test/golden/ --concurrency=1
```

Ганц файл:

```sh
cd app
flutter test --update-goldens --run-skipped \
    test/golden/design_screenshots_test.dart --concurrency=1
```

- `--run-skipped` нь `dart_test.yaml`-ын `golden` тагийн алгасалтыг давна.
- `--concurrency=1` нь Windows дээрх socket flakiness-ээс хамгаална.
- `--update-goldens`-гүй ажиллуулбал одоогийн зургуудыг **шалгана** (өөрчлөгдөөгүй
  эсэхийг). Өөр машин дээр пиксел зөрч болзошгүй — тиймээс эдгээр нь CI-ийн
  баталгаа биш.

Зураг `app/test/golden/images/` дор бууна.

## Дизайн санаатай өөрчлөгдвөл

1. Кодоо зас.
2. Зургуудаа дахин гарга (дээрх команд).
3. **Шинэ зургуудыг НҮДЭЭР нээж хар.** Ялангуяа:
   - хоосон хайрцаг `▯` байна уу (кирилл эсвэл `₮` алдагдсан уу),
   - текст давхарласан эсвэл тайрагдсан уу,
   - дэлгэц бүхэлдээ хоосон болчихсон уу.
4. Дараа нь commit хий.

> ⛔ **Сохроор `--update-goldens` хийж дараа нь харалгүй commit хийхийг хориглоно.**
> Тэр агшинд зурган хяналт нь зөвхөн файл шинэчилдэг зан үйл болж хувирна —
> дээрх хоёр алдаа яг тэгж мултарна. Зураг харагдахгүй бол зураг байхын утга алга.

Шинэ дэлгэц (маршрут) нэмсэн бол: зураг гаргах тестээ бич, гаргасан зургаа хар,
дараа нь `_routeScreenshotPrefixes`-д угтвараа нэм.
