# Тахь — брэнд систем v0.1

> Эзэнгүй, зэрлэг, чөлөөт. Монголын талын цорын ганц хэзээ ч гаршаагүй адуу.

## Утга ба өнгө аяс

Тахь (Przewalski адуу) = дэлхийн цорын ганц хэзээ ч гаршуулагдаагүй зэрлэг адуу. Гэрийн адуунаас ялгарах **гол харагдах шинж = богино босоо сойз дэл** (унжсан дэлгүй). Брэндийн mark энэ детал дээр тогтоно.

Өнгө аяс: зэрлэг + чөлөөт + монгол тал + тэсвэр + premium-earthy. Корпораци биш, нийтийн өмч.

## Палитр

| Токен | Hex | Хэрэглээ |
|---|---|---|
| `--takhi-gold` | `#C99A3C` | Үндсэн — тахийн зүсний шаргал; «такси-шар»-ын өв санагдуулна |
| `--takhi-gold-deep` | `#A67C28` | Gold-ийн гүн сүүдэр, gradient |
| `--ink` | `#1C1A16` | Дэл/хөл/бараан — near-black, бага зэрэг дулаан |
| `--steppe` | `#2E6E5E` | Хоёрдогч accent (интерактив/амжилт) — тал нутгийн ногоон-номин |
| `--paper` | `#F4F1E9` | Дулаан цайвар суурь |
| `--sand` | `#E7DEC9` | Зөөлөн гадаргуу, картын дэвсгэр |

Логоны хос: `--ink` + `--takhi-gold`. Хоёр өнгө — app icon-д хамгийн цэвэр.

## Типографи

- **Гарчиг/wordmark:** geometric, бага зэрэг өргөн, бат бөх sans (ж: Clash / Space Grotesk маягийн). Кирилл «Тахь» тод, өргөнтэй.
- **Их бие:** уншихад тухтай sans (Inter / IBM Plex Sans маягийн, кирилл дэмжсэн).
- **Тоо/дата:** tabular sans эсвэл mono (таксиметрийн том тоонд).

## Логоны зарчим

- Mark = тахийн толгой+хүзүү профайл, **босоо сойз дэл** нь ялгах детал.
- 24px app icon дээр уншигдана; ганц өнгөөр (silhouette) ажиллана.
- App icon: gold дэвсгэр + ink адуу (утсан дэлгэц дээр тодрох, такси-шар өв).
- Wordmark: mark зүүн талд + «Тахь» ink өнгөөр.

## Дуу хоолой (voice)

Шулуун, эрх чөлөөтэй, чамирхалгүй. «Эзэнгүй унаа.» «Голд нь хэн ч байхгүй.» Амлалт биш — баримт. Монголоор (кирилл), англи зэрэгцээ.

## Эцсийн mark ба ассетууд (v1, 2026-07-21)

Давхиж буй тахь — босоо сойз дэлтэй silhouette. Гарал: концепцийг Meshy (nano-banana-pro) AI-аар үүсгэж, Python-оор silhouette цэвэрлэж (bevel/сүүдэр хассан), брэнд-өнгөнд (#C99A3C / #1C1A16) буулгаж, төвлүүлж эцэслэв. Бүх хэмжээнд (28px хүртэл) уншигдана.

Файлууд (`brand/out/`):
