# Stitch дизайн хүлээн авах фолдер

Энд Google Stitch-ээс гаргасан дизайнаа хийнэ. Би эндээс уншиж, Flutter код руу буулгана.

## Дэлгэц бүрт юу хэрэгтэй вэ

| Файл | Заавал уу | Яагаад |
|---|---|---|
| `S<дугаар>_<нэр>.png` | **Тийм** | Дэлгэцийн зураг. Би үүнийг нүдээрээ хараад дүрсийг ойлгоно. |
| `S<дугаар>_<нэр>.html` | Их тустай | Stitch-ийн «Code» хэсгээс хуулсан HTML/CSS. Дотор нь **яг** өнгөний код, фонтын хэмжээ, зай байгаа тул би таамаглахгүй, тодорхой буулгана. |
| `S<дугаар>_<нэр>.txt` | Сонголттой | Нэмэлт тайлбар: «энэ товчийг илүү том», «энэ өнгийг өөрчил» гэх мэт. |

**Жишээ:**
```
S21_taximeter-running.png
S21_taximeter-running.html
S04_home.png
S04_home.html
```

Нэр өгөх нь төвөгтэй бол зүгээр л файлаа энэ фолдерт хийгээд «S21-ийнх» гэж хэлээрэй — би өөрөө нэрлэж эмхэлнэ.

## Stitch-ээс хэрхэн гаргах вэ

1. Дэлгэцээ үүсгэсний дараа **зургийг** татаж авах (эсвэл дэлгэцийн зураг авах) → `.png`
2. **Code** товчоор HTML/CSS-ийг хуулж авах → `.html` файлд буулгах
3. Хоёуланг нь энэ фолдерт хийх

## Би юу хийх вэ

- Таны дизайнаас **өнгө, фонт, зай, радиус, сүүдрийг** гаргаж аваад `app/lib/theme/takhi_theme.dart`-д
  нэгдсэн дизайн систем болгож суулгана. Ингэснээр дараагийн дэлгэцүүд автоматаар тааран орно.
- Дэлгэц бүрийн **бүтэц, шатлал, элементийн байрлалыг** Flutter виджет болгож дахин барина.
- **Ажиллагааг нь хөндөхгүй** — навигаци, Nostr холболт, таксиметрийн тооцоо, аюулгүйн урсгал
  бүгд хэвээр. Зөвхөн харагдах давхарга солигдоно.
- Дуусмагц дэлгэцийн зураг авч танд харуулна — таны Stitch дизайнтай зэрэгцүүлж харьцуулахаар.

## Stitch-ийн статик дизайн шууд буудаггүй хэсгүүд

Эдгээрийг би тохируулж буулгана (танаас нэмэлт юм шаардахгүй):

- **Газрын зурагтай дэлгэцүүд** (S5, S6, S14) — Stitch газрын зургийг зөвхөн зурган байдлаар
  үзүүлнэ. Би бодит OSM газрын зураг дээр таны зурсан давхаргыг (pin, карт, товч) буулгана.
- **Камер / QR уншигч** (S18) — статикаар харагдана, бодит дээр камерын урсгал орно.
- **Амьд өөрчлөгддөг тоо** (S21 таксиметр, S10 аялал) — Stitch нэг агшны байдлыг зурна.
  Би тоо өсөх, төлөв солигдох хөдөлгөөнийг нэмнэ.

## Зөвлөмж: бүх 31-ийг нэг дор бүү зур

Эхлээд **1 дэлгэц** (жишээ нь S21 таксиметр эсвэл S4 нүүр) зураад надад өгөөрэй.
Би кодод буулгаад буцааж харуулна. Таны хүлээж байсантай таарч байвал үлдсэнийг нь итгэлтэй үргэлжлүүлнэ.
Таараагүй бол нэг дэлгэцийн ажил л дэмий болно, 31-ийнх биш.
